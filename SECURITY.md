# Security policy

## Supported versions

The latest release is the only supported version. Older tagged versions do not receive backported fixes.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security findings.

Email the maintainer directly: **security@thisismyurl.com**

Include:

- Affected plugin version.
- WordPress core version and PHP version.
- Steps to reproduce.
- Suggested fix or mitigation, if you have one.

You can expect an acknowledgement within 5 business days. Coordinated disclosure is appreciated — public credit is given on request.
